# V42 — Adobe Fonts / Proxima Nova

Basado en el sitio V41 Final. Se agregó el kit Adobe Fonts `snc0oco` a los 13 HTML y una hoja de estilos de tipografía compartida. Se conservan imágenes, scripts, estilos originales y rutas. No se incluyeron archivos de fuente de Adobe.

## Verificación
- Publicar por HTTPS (GitHub Pages).
- Verificar que el kit Adobe Fonts TKC esté activo y autorizado para el dominio publicado.
- DevTools > Network > Font: fuentes sin errores de red.
- DevTools > Computed > Rendered Fonts: Proxima Nova, en Windows y Android.
- Revisar en Safari/iOS y Chrome/Android la carga y el fallback Arial si Adobe está bloqueado.
